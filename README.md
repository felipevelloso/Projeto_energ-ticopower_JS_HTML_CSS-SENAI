# Projeto_energ-tico_JS_HTML_CSS-SENAI

💡 Desafios Superados
Desafio 1: Sincronizar cores dinamicamente
Solução: Usei variáveis CSS combinadas com manipulação via JavaScript para atualizar múltiplos elementos simultaneamente.

Desafio 2: Gerenciar estado da energia
Solução: Implementei uma variável de estado com funções específicas para atualizar e resetar o progresso.

Desafio 3: Manter código organizado
Solução: Separei o código em arquivos distintos e usei nomes descritivos para funções e variáveis.
